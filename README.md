# ☕ كوستا ريكا كافيه — موقع المنيو

موقع منيو كامل + لوحة تحكم، مستضاف مجاناً على **GitHub Pages** وبيفضل شغال طول ما المستودع موجود.
مفيش سيرفر ولا قاعدة بيانات ولا مصاريف شهرية.

## المميزات

- 🎨 تصميم عربي RTL، ألوان الكافيه الذهبية، ومتوافق مع الموبايل.
- 🔎 بحث فوري في كل الأصناف + فلترة بالأقسام.
- 🛒 سلة طلب: العميل يختار الأصناف ويبعت الطلب على **واتساب** برسالة جاهزة فيها التفاصيل والإجمالي.
- ⚙️ **لوحة تحكم** (`admin.html`) لتعديل الأصناف والأسعار والأرقام والألوان، والنشر على الموقع بزرار واحد.
- 👁️ معاينة التعديلات قبل النشر.
- 💾 نسخة احتياطية: تنزيل / استيراد ملفات JSON.
- 📲 يعمل كتطبيق (PWA) وينفع يتثبّت على الموبايل ويشتغل أوفلاين.
- 🖨️ زرار طباعة منيو ورقية.
- 🔍 بيانات SEO + Open Graph لمشاركة اللينك على واتساب/فيسبوك.

## 1) النشر أول مرة (خطوات بسيطة)

### أ. اعمل مستودع على GitHub

1. اعمل حساب على [github.com](https://github.com) لو معندكش.
2. من الصفحة الرئيسية: **New repository**.
3. الاسم: `costa-rica-cafe` — النوع: **Public** — واضغط **Create repository**.

### ب. ارفع ملفات المشروع

1. في صفحة المستودع اضغط **Add file → Upload files**.
2. اسحب **كل محتويات** المجلد (مهم إنك ترفع المجلدات `assets` و `data` كاملة، وكمان الملفات المخفية زي `.nojekyll`).
3. اضغط **Commit changes**.

> بديل أسهل: استخدم GitHub Desktop أو أوامر Git:
> ```bash
> git init
> git add .
> git commit -m "أول نسخة من موقع كوستا ريكا"
> git branch -M main
> git remote add origin https://github.com/USERNAME/costa-rica-cafe.git
> git push -u origin main
> ```

### ج. فعّل GitHub Pages

1. من المستودع: **Settings → Pages**.
2. تحت **Build and deployment** اختار **Source: Deploy from a branch**.
3. **Branch: `main`** و **Folder: `/ (root)`** ثم **Save**.
4. استنى من دقيقة لدقيقتين، وهتلاقي اللينك:
   `https://USERNAME.github.io/costa-rica-cafe/`

الموقع جاهز ✅ — ولوحة التحكم على:
`https://USERNAME.github.io/costa-rica-cafe/admin.html`

## 2) ربط لوحة التحكم بـ GitHub (مرة واحدة)

لوحة التحكم بترفع التعديلات مباشرة على المستودع عن طريق GitHub API، ومحتاجة **توكن** خاص بيك.

1. افتح [إعدادات التوكنات](https://github.com/settings/personal-access-tokens/new) (Fine-grained token).
2. **Token name**: `costa-rica-admin` — **Expiration**: أطول فترة متاحة.
3. **Repository access**: `Only select repositories` → اختار `costa-rica-cafe`.
4. **Permissions → Repository permissions → Contents: Read and write**.
5. اضغط **Generate token** وانسخ التوكن (بيظهر مرة واحدة بس).

في لوحة التحكم:

6. افتح تبويب **🔗 النشر والنسخ الاحتياطي**.
7. اكتب اسم المستخدم، اسم المستودع، الفرع (`main`)، والصق التوكن.
8. اضغط **اتصال واختبار** — لازم تظهر رسالة "متصل ✓".
9. خلاص، زر **🚀 نشر التغييرات** هيشتغل.

> 🔒 التوكن بيتخزن في متصفحك انت بس (localStorage) ومش بيتبعت لأي مكان غير GitHub.
> استخدمه من جهازك الشخصي فقط، ولو حسّيت إنه اتسرّب امسحه واعمل واحد جديد.

## 3) إزاي تعدّل الموقع بعد كده

افتح `admin.html` من أي موبايل أو كمبيوتر:

| التبويب | بتعمل إيه |
|---|---|
| **📋 الأصناف والأسعار** | تعديل الاسم والسعر والوصف مباشرة، إضافة/حذف/إخفاء صنف، ترتيب الأقسام والأصناف بالأسهم |
| **🏪 بيانات الموقع** | الاسم، جملة الترحيب، رقم واتساب، أرقام التليفون، العنوان، المواعيد، فيسبوك/إنستجرام/الخريطة، العملة، الملاحظات، وألوان الموقع |
| **🔗 النشر والنسخ الاحتياطي** | ربط GitHub، النشر، تنزيل/استيراد نسخة JSON |

**دورة العمل:**

1. عدّل اللي انت عايزه.
2. اضغط **👁️ معاينة** للتأكد من الشكل (بتفتح الموقع بالمسودة قبل النشر).
3. اضغط **🚀 نشر**.
4. استنى دقيقة واعمل تحديث للموقع.

> التعديلات بتتحفظ كمسودة على المتصفح أول ما تكتب، فلو قفلت الصفحة مش هتضيع.
> المسودة مش بتظهر للناس غير بعد النشر.

### من الموبايل كتطبيق

افتح لوحة التحكم في المتصفح → **Add to Home Screen**، هتفتح زي تطبيق.

## 4) ملفات المشروع

```
/
├── index.html               ← الموقع (الصفحة الرئيسية)
├── admin.html               ← لوحة التحكم
├── manifest.json            ← إعدادات تطبيق الموبايل (PWA)
├── sw.js                    ← العمل أوفلاين
├── .nojekyll                ← مهم لـ GitHub Pages
├── data/
│   ├── menu.json            ← الأصناف والأسعار (ده اللي لوحة التحكم بتعدله)
│   └── site.json            ← بيانات الكافيه والألوان
├── assets/
│   ├── css/site.css         ← ستايل الموقع
│   ├── css/admin.css        ← ستايل لوحة التحكم
│   ├── js/shared.js         ← دوال مشتركة
│   ├── js/site.js           ← تشغيل الموقع والسلة
│   ├── js/admin.js          ← تشغيل لوحة التحكم والنشر
│   └── icon*.png / icon.svg ← أيقونات التطبيق
└── README.md
```

> لو حبيت تعدّل من غير لوحة التحكم: `data/menu.json` و `data/site.json` ملفات نصية بسيطة، تقدر تفتحها من GitHub وتعدّل (**Edit** ← **Commit changes**) والموقع يتحدّث لوحده.

## 5) دومين خاص (اختياري)

لو عندك دومين (مثلاً `costaricacafe.com`):

1. من **Settings → Pages → Custom domain** اكتب الدومين واضغط Save.
2. في شركة الدومين اضبط الدومين:
   - `www` → **CNAME** → `USERNAME.github.io`
   - الدومين الرئيسي (بدون www) → **A** → `185.199.108.153` و `185.199.109.153` و `185.199.110.153` و `185.199.111.153`
3. ارجع لـ Pages وفعّل **Enforce HTTPS** بعد ما يظهر ✅.

## 6) تشغيل محلي (اختياري)

الموقع بيقرأ ملفات JSON، فمحتاج سيرفر محلي (مش هيفتح بالدبل كليك):

```bash
cd costa-rica-cafe
python3 -m http.server 8000
# افتح http://localhost:8000
```

## 7) استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| الموقع بيقول "المنيو مش قادر يحمّل" | تأكد إن مجلد `data` مرفوع وفيه `menu.json` و `site.json` |
| فشل النشر: 401 | التوكن غلط أو انتهت صلاحيته — اعمل واحد جديد |
| فشل النشر: 403 | التوكن مش عليه صلاحية **Contents: Read and write** |
| فشل النشر: 404 | اسم المستخدم أو المستودع غلط، أو الفرع مش `main` |
| التعديلات مش ظاهرة على الموقع | استنى دقيقة–دقيقتين، واعمل تحديث (Hard refresh) |
| الصفحة 404 بعد النشر | راجع **Settings → Pages** إن المصدر `main` و `/ (root)` |
| الأيقونة مش بتظهر على الموبايل | امسح الكاش أو أعد إضافة التطبيق للشاشة الرئيسية |
