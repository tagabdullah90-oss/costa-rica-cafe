النشر والنسخ الاحتياطي

اربط حساب GitHub مرة واحدة، وبعدها زر «نشر» بيرفع التعديلات على الموقع مباشرة.

🔗 ربط GitHub

التوكن بيتخزن على جهازك انت بس (في المتصفح)، ومش بيتبعت لأي مكان غير GitHub.

إزاي أعمل التوكن؟
  1. افتح إعدادات التوكنات.
  2. Token name: أي اسم، وExpiration: خليه أطول فترة ممكنة.
  3. Repository access: اختار Only select repositories وحدد مستودع الموقع.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. اضغط Generate token وانسخ التوكن هنا.

لو التوكن اتسرّب، ارجع لنفس الصفحة وامسحه فوراً.

🚀 النشر

النشر بيرفع data/menu.json و data/site.json للمستودع. GitHub Pages بيحدّث الموقع خلال دقيقة تقريباً.
